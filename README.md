# Final Project – Winter 2025 – Programming 2 Course

## Description
A small game built on a game engine provided by the course instructors.
The player must catch a key to unlock access to the next level and ultimately complete the game.

### Technologies
The game is written in Java, using an external module developed by the instructors.
Each level's design is loaded from a text file, where every character represents an in-game object.
Each enemy has unique abilities to attack the player.

### How to run the game
Open any Java editor and run the code.
You can play directly in the terminal.
